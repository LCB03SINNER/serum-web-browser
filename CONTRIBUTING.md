# Contributing

Thanks for your interest in contributing to Serum Web Browser.

## Development Setup

```bash
npm install
npm run dev
```

## Pull Requests

- keep changes focused and well documented
- add tests for bug fixes when possible
- ensure the app still builds with `npm run build`
- follow secure coding practices

## Code Style

- prefer simple, readable JavaScript
- avoid unsafe URL handling
- document security-sensitive changes clearly
