# Security Policy

## Reporting a Security Vulnerability

Please report security issues privately to the repository maintainers by email or through GitHub private reporting if available.

Do not disclose vulnerabilities publicly until a fix has been published.

## Supported Versions

This project is a starter prototype. Security updates are handled on the latest main branch.

## Response Expectations

We aim to review and triage security reports within 72 hours and provide a remediation plan as soon as possible.

## Best Practices for Contributors

- validate input before navigation
- do not introduce unsafe browser behaviors
- prefer secure defaults
- keep dependencies updated
